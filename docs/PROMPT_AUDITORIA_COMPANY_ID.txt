Eres un auditor senior de bases de datos y aplicaciones multi-tenant. Este proyecto Next.js + Supabase (PostgreSQL) está en PRODUCCIÓN y NO PUEDE FALLAR. Tu tarea es realizar una auditoría EXHAUSTIVA del uso de `company_id` en toda la aplicación y base de datos, trazar el flujo completo desde el login hasta cada feature, y proponer fixes exactos (sin aplicarlos).

## Contexto del problema

El proyecto tuvo 3 errores en producción por inconsistencias con `company_id`:

1. `action_template` tenía `company_id = NULL` en todas sus filas (38) pero la política RLS exigía `is_tenant_allowed(company_id)` que devuelve `false` para NULL → nadie podía editar gestiones.
2. Se dropeó `company_id` de `action_template` pero la función PostgreSQL `is_action_template_tenant_allowed()` aún la referenciaba → `column at.company_id does not exist`.
3. El frontend enviaba `""` (string vacío) para campos UUID opcionales (`auto_email_template_id`, `default_issuer_role`) → `invalid input syntax for type uuid: ""`.

La raíz: se modificó la estructura de la BD sin auditar TODAS las dependencias (funciones, vistas, triggers, políticas RLS, constraints, índices, código de la app, sanitización de inputs).

## FASE 1: Auditoría de Base de Datos

Conectarse a PostgreSQL y ejecutar estas queries de auditoría:

### 1.1 Todas las tablas con `company_id`

```sql
SELECT table_name, is_nullable, data_type
FROM information_schema.columns
WHERE table_schema = 'public' AND column_name = 'company_id'
ORDER BY table_name;
```

### 1.2 Para cada tabla: filas totales, NULL, % NULL

```sql
SELECT count(*) as total,
       count(company_id) as not_null,
       count(*) - count(company_id) as null_count,
       round(100.0 * (count(*) - count(company_id)) / nullif(count(*), 0), 1) as pct_null
FROM <tabla>;
```

### 1.3 Todas las políticas RLS que referencian `company_id`

```sql
SELECT tablename, policyname, cmd, roles, qual, with_check
FROM pg_policies
WHERE schemaname = 'public'
  AND (qual ILIKE '%company_id%' OR with_check ILIKE '%company_id%')
ORDER BY tablename, cmd;
```

Para cada política, verificar:
- ¿Permite `company_id IS NULL`?
- ¿Es consistente con las otras políticas de la misma tabla?
- ¿La función `is_tenant_allowed(company_id)` devuelve `false` para NULL?

### 1.4 Todas las funciones que referencian `company_id`

```sql
SELECT proname, pg_get_functiondef(oid)
FROM pg_proc
WHERE pronamespace = 'public'::regnamespace
  AND prosrc ILIKE '%company_id%'
ORDER BY proname;
```

Para cada función:
- ¿Qué tabla referencia?
- ¿La columna `company_id` aún existe en esa tabla?
- ¿Qué pasa si `company_id` es NULL?
- ¿Es `SECURITY DEFINER`? ¿Bypassa RLS?
- ¿Quién la llama? (buscar en triggers, políticas, otras funciones)

### 1.5 Definición completa de `is_tenant_allowed`

```sql
SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'is_tenant_allowed';
```

Analizar:
- ¿Qué pasa cuando recibe NULL?
- ¿Considera `user_clients`?
- ¿Considera usuarios `internal` sin `user_clients`?
- ¿Hay edge cases?

### 1.6 Todas las vistas que referencian `company_id`

```sql
SELECT viewname, definition
FROM pg_views
WHERE schemaname = 'public' AND definition ILIKE '%company_id%';
```

### 1.7 Todos los triggers que referencian `company_id`

```sql
SELECT tgname, pg_get_triggerdef(oid), tgrelid::regclass AS table_name
FROM pg_trigger
WHERE pg_get_triggerdef(oid) ILIKE '%company_id%'
  AND NOT tgisinternal;
```

### 1.8 Todos los constraints (FK) que referencian `company_id`

```sql
SELECT conname, conrelid::regclass AS table_from, confrelid::regclass AS table_to,
       pg_get_constraintdef(oid)
FROM pg_constraint
WHERE contype = 'f'
  AND conname ILIKE '%company_id%'
ORDER BY conrelid::regclass::text;
```

### 1.9 Si RLS está habilitado por tabla

```sql
SELECT relname, relrowsecurity
FROM pg_class
WHERE relname IN (
  SELECT table_name FROM information_schema.columns
  WHERE table_schema = 'public' AND column_name = 'company_id'
)
ORDER BY relname;
```

### 1.10 Índices que incluyen `company_id`

```sql
SELECT indexname, tablename, indexdef
FROM pg_indexes
WHERE schemaname = 'public' AND indexdef ILIKE '%company_id%'
ORDER BY tablename;
```

### 1.11 Verificar columnas dropeadas pero aún referenciadas

Para cada función encontrada en 1.4, verificar que todas las columnas que referencia aún existen:

